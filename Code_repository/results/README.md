# Result tables

| File | Content |
|---|---|
| `forward_R13_ivw_fdr.csv` | FinnGen R13 IVW estimates with FDR and Bonferroni correction |
| `forward_AAAgen_ivw_fdr.csv` | AAAgen IVW estimates with FDR and Bonferroni correction |
| `cross_cohort_lookup.csv` | Cross-cohort comparison of all 140 taxa |
| `sensitivity_all.csv` | Heterogeneity, pleiotropy and directionality for all taxa and outcomes |
| `loo_summary.csv` | Leave-one-out summary statistics |
| `presso_candidates.csv` | MR-PRESSO results for candidate taxa |
| `reverse_all.csv` | Reverse MR estimates |
| `Additional_file_1_Tables_S1-S8.xlsx` | Formatted supplementary Tables S1–S8 |

The analysis script also writes full forward results to `results_R13_AAAgen_v2/` when rerun from the repository root.
